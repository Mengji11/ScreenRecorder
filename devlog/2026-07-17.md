# 2026-07-17 开发日志

## 问题修复（对比 Cap/Recordly/OpenScreen 三个参考项目）

### 高优先级：线程安全修复
- `_state` 字段加 `volatile`，确保后台采集线程读到最新状态
- `_mouseClicks` 列表加 `_mouseClicksLock` 锁保护，采集线程写入和 UI 线程清理不再竞态
- `AudioCaptureService._isRecording` 加 `volatile`
- Audio DataAvailable 回调中捕获 `_systemWriter`/`_microphoneWriter` 本地引用，避免 Stop 和回调之间的竞态

### 高优先级：资源泄漏修复
- `ApplyWatermark` 中 Font/Brush 改为 `using` 语句，异常时不再泄漏 GDI+ 对象
- Font 改为实例字段 `_watermarkFont` 缓存，避免每帧创建新 Font（30fps = 30次/秒）
- `SaveRecordingBackground` 和 `SaveFramesAsVideo` 中 Process 对象加 `using`
- `PauseRecording`/`ResumeRecording`/`StopRecording` 中旧 CancellationTokenSource 正确 Dispose
- `IsSystemAudioAvailable`/`IsMicrophoneAvailable` 改为 `static`，COM 对象加 `using`
- MainWindow 中不再为音频检查创建临时 AudioCaptureService 实例

### 高优先级：关闭竞争修复
- `Window_Closing` 在 `_recorder.IsSaving` 时弹窗询问用户是否等待保存完成
- 最多等待 60 秒后自动继续关闭
- 所有 `Dispatcher.Invoke` 调用加 `try-catch`，防止关闭时 Dispatcher 已销毁导致异常

### 中优先级：性能优化
- 帧率精度：`int interval = 1000 / fps` 改为 `double intervalMs = 1000.0 / fps`，消除整数截断误差
- 帧采集循环：改进 Sleep/SpinWait 策略（>10ms 用 Sleep(1)，1-10ms 用 Sleep(0)，<1ms 用 SpinWait）
- 帧率漂移修正：落后超过一帧时自动重置 nextFrameTime
- `BitmapToBgr24` 使用 `ArrayPool<byte>.Shared.Rent()`，避免每帧分配 6MB byte[]

### 中优先级：历史记录修复
- `RecorderService` 新增 `CaptureWidth`/`CaptureHeight` 属性
- `Recorder_RecordingCompleted` 中使用实际采集分辨率替代 `SystemParameters.PrimaryScreenWidth/Height`
- 区域/窗口录制时历史记录现在显示正确的分辨率

## 参考项目分析总结

### Cap (Rust/Tauri)
- GPU 硬件编码自动检测（NVENC/QSV/AMF/MF）+ 软件回退
- 零拷贝路径（像素格式匹配时无需转换）
- 帧丢失追踪器 + 时间戳异常处理
- D3D 设备共享（采集和编码使用同一设备）

### Recordly (Electron/C++/Swift)
- WASAPI loopback + 间隙填充 + fade-in 防咔音
- BGRA→NV12 CPU 转换 + Media Foundation H.264
- 静态场景间隙填充（重复最后一帧）
- 分离音频轨道（录制时不混合）
- 乐观 UI 模式（立即打开编辑器，后台处理音频）

### OpenScreen (Electron/React)
- MediaRecorder 磁盘流式写入（避免渲染进程 OOM）
- WebCodecs 导出管线 + 后压管理
- 编码器卡顿检测 + 自动重试
- 源文件快速复制路径（无编辑时直接拷贝）

## 第二轮问题修复（用户反馈4个问题）

### 问题1: 软件闪退
- 根因：`Window_Closing` 中 `Dispatcher.CurrentDispatcher.Invoke` 空操作循环 + `Thread.Sleep(200)` 阻塞 UI 线程导致死锁
- 修复：改为短时间轮询（3秒）+ `Application.Current.Dispatcher.Invoke` 处理后台消息

### 问题2: 画面旋转抖动
- 根因：`ArrayPool<byte>.Shared.Rent()` 返回的缓冲区可能大于 `width*height*3`，导致写入文件时每帧数据量不一致，FFmpeg 解析帧错位
- 修复：写入时使用精确长度 `bgrLen = _frameWidth * _frameHeight * 3`

### 问题3: 历史记录不显示
- 根因：`Recorder_RecordingCompleted` 使用 `Dispatcher.Invoke` 阻塞式调用，窗口关闭时抛异常被 catch 吞掉
- 修复：所有事件处理器统一改为 `Dispatcher.BeginInvoke` 非阻塞调用

### 问题4: 水印不显示
- 根因：`new Font("Microsoft YaHei", ...)` 在后台线程创建时字体名匹配失败
- 修复：改为 `FontFamily.GenericSansSerif` 通用字体族
