# 2026-07-19 开发日志

## 代码审查与修复

### 高优先级修复
- **ArrayPool buffer 泄漏**：`CaptureFrame()` 中 `BitmapToBgr24()` 返回的 buffer 现在包裹在 `try-finally` 中，`ArrayPool.Return` 确保异常时也能归还（6MB/帧的泄漏）
- **MMDeviceEnumerator COM 泄漏**：`StartMicrophoneCapture()` 中 `MMDeviceEnumerator` 添加 `using`，每次恢复录制不再泄漏 COM 对象
- **鼠标高亮位置偏移**：窗口录制/非主显示器录制时，鼠标坐标现在正确减去捕获区域偏移。新增 `_captureOffsetX`/`_captureOffsetY` 字段，在 `StartRecording()` 中根据模式计算
- **RecordingControlBar 内存泄漏**：`OnClosed` 中取消订阅 `_recorder` 事件，避免旧实例被 `RecorderService` 持有

### 中优先级修复
- **历史记录批量删除**：`HistoryService` 新增 `RemoveEntries()` 批量方法，单次 JSON 写入替代逐条写入
  - `HistoryWindow.LoadHistory()` 过滤过期文件 → 批量移除
  - `HistoryWindow.BtnDeleteSelected_Click` → 批量删除
- **音频设备禁用未持久化**：`CheckFfmpegAvailability()` 中禁用音频设置后保存到磁盘
- **临时文件泄漏**：`SaveRecordingBackground` 异常时清理临时 `.bin` 文件
